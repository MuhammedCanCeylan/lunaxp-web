# LunaXP Web v0.1.0

**Release date:** September 21, 2026

This is the first public development release of LunaXP Web.

## Highlights
- Windows XP Luna-inspired web desktop
- custom WindowManager and taskbar integration
- classic utilities and games
- XP-era media application modules
- SWF playback through Ruffle
- browser-native media playback
- ISO image creation in the Nero-inspired module
- VLC-style playback through WebVLC
- no desktop-streaming dependency

## Development Status
`v0.1.0` is a usable development release, not the final stable version.

## Next Versions
- bug fixes: `v0.1.1`, `v0.1.2`, ...
- new apps/features: `v0.2.0`, `v0.3.0`, ...
- stable milestone: `v1.0.0`
