Ozellikler:
- XP tarzi File/Edit/View/Insert/Format/Help menuleri
- Standard toolbar + formatting toolbar + ruler + status bar
- contenteditable Rich Text editor
- New: Rich Text / Text / Unicode Text
- Open: RTF / TXT / Unicode TXT / HTML
- Save: RTF / TXT / Unicode TXT / HTML
- Basit gercek RTF import/export
- TXT kaydinda formatting loss uyari dialogu
- Bold / Italic / Underline
- Font family / point size
- Text color palette
- Left / center / right alignment
- Bullets
- Undo / redo / cut / copy / paste
- Find / Find Next / Replace / Replace All
- Date and Time insert
- Paragraph dialog
- Tabs dialog
- Print Preview + Print
- Autosafe draft in localStorage
- No native alert/confirm/prompt
- No second XP titlebar/taskbar
