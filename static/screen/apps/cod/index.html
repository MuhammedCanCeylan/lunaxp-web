About This Simulator
Call of Duty - XP Nostalgia Simulator

Lightweight fan-made menu and procedural mini FPS written as a single HTML file for an iframe-based Windows XP desktop simulation.

Engine: HTML5 Canvas + JavaScript
Audio: Web Audio API procedural synthesis
Assets: none required beyond your desktop icon.png

Call of Duty is a trademark of its respective rightsholders. This project includes no original game executable, retail data, extracted maps, voices, cinematics, or music.
