POWERPOINT 2003 STYLE MODULE

Target default:
static/screen/apps/powerpoint/

Auto-detected existing names:
powerpoint, powerpnt, powerpoint2003, ppt

Engine:
PPTist - https://github.com/pipipi-pikachu/PPTist
License: AGPL-3.0

The final installation is static. Node.js is only required while the installer
downloads dependencies and builds PPTist with Vite.

Runtime needs no Node server, backend, Docker, VM, ISO, streaming, or Office.

PPTX compatibility is not byte-perfect: very complex Office masters, charts,
animations, nested content, or unsupported styles can differ.

Registry.js is not modified.
