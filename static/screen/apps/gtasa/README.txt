GTA San Andreas browser module

Target:
static/screen/apps/gtasa/

Required:
- index.html
- icon.png
- assets/ (generated by Vite)

Recommended URL:
./apps/gtasa/index.html

Recommended WindowManager registration:
{
    id: 'gtasa',
    title: 'GTA San Andreas',
    icon: './apps/gtasa/icon.png',
    url: './apps/gtasa/index.html',
    width: 1050,
    height: 720,
    resizable: true,
    desktop: true
}

Run through the same HTTP server as the XP shell.
Do not use file:/// for this Vite/WebGL application.
