# Changelog

All notable changes to LunaXP Web will be documented here.

## [0.1.0] - 2026-09-21

### Added
- Initial public development release.
- Windows XP Luna-inspired desktop architecture.
- WindowManager, taskbar and app registry integration.
- iframe-isolated application modules.
- classic utilities and retro game modules.
- PowerDVD-inspired media player.
- K-Lite / Codec Tweak Tool-inspired module.
- Ruffle-based Flash Player module.
- Nero Burning ROM-inspired ISO creator.
- QuickTime Player-inspired module.
- RealPlayer-inspired module.
- VLC / WebVLC integration.
- initial licensing and third-party notice structure.

### Project Rules
- No Moonlight, Sunshine or Parsec streaming.
- No background streaming daemon.
- No virtual gamepad driver requirement.
- No project-wide COOP/COEP requirement.
- Prefer existing open-source ports/remakes before custom recreation.
